# Música de la invitación

El reproductor usa el archivo local `volvi-a-nacer.mp3` de esta carpeta.

La página intenta iniciar la música medio segundo después de abrirse. Si el navegador bloquea el inicio automático con sonido, la primera interacción de la persona con la página intentará activarla. El botón fijo `♫` pausa y reanuda la canción.
